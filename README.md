# GitHub Pages upload bundle

Upload the files in this folder to the root of your GitHub repository. `config.js` is already configured for the Apps Script endpoint provided for this study and remote collection is enabled.

After uploading, use **Settings → Pages → Deploy from a branch → main → /(root) → Save**. Wait for the site build, open the Pages URL, and complete one test run. Confirm a new row appears in `ParticipantSessions` and 30 rows appear in `ScenarioResponses` before recruiting participants.

This bundle contains participant-facing study files only. Do not add the private researcher kit, Apps Script source, GroundTruth CSV, or participant exports to a public repository. Complete the institution-specific placeholders in `ethics.html` and the information sheet and obtain the required ethics approval before recruitment.
